# List of Classes and IDs in NailTool Admin Header

| Class Name          | Description                       | HTML Element                 |
|---------------------|---------------------------------|------------------------------|
| `nailtool-header`   | Main header of NailTool Admin    | `<nav>`                      |
| `logo-section`      | Logo and app name container      | `<div>`                      |
| `nav-menu`          | Navigation menu list             | `<ul>`                       |
| `nav-dashboard`     | Dashboard navigation link        | `<a>` (Dashboard)            |
| `nav-products`      | Products navigation link         | `<a>` (Products)             |
| `nav-orders`        | Orders navigation link           | `<a>` (Orders)               |
| `nav-customers`     | Customers navigation link        | `<a>` (Customers)            |
| `nav-settings`      | Settings navigation link         | `<a>` (Settings)             |
| `user-profile`      | User profile section (avatar + welcome) | `<div>`              |
| `language-selector` | Language selector container      | `<div>`                      |
| `btn-vietnamese`    | Vietnamese language button       | `<button>`                   |
| `btn-english`       | English language button          | `<button>`                   |
